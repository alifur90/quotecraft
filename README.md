# QuoteCraft - Premium Quotation Maker

QuoteCraft is a fast, beautiful, and completely client-side web application designed for freelancers, agencies, and small businesses to generate professional quotations effortlessly. It works directly in the browser without requiring any login, backend, or database.

## ✨ Key Features

* **No Login Required:** Works instantly in your browser.
* **100% Client-Side:** All data (quotations, business profile, logo) is securely saved in your browser's `localStorage`.
* **Live A4 Preview:** See your quotation update in real-time on a digital A4 canvas.
* **Multiple Templates:** Choose from 5 premium document styles (Minimal, Modern, Corporate, Creative, Elegant).
* **Smart Calculations:** Auto-calculates subtotals, discounts (fixed/percentage), tax/VAT, and extra charges.
* **PDF Export & Print:** One-click download as a clean PDF or print directly using browser capabilities.
* **Business Profile:** Save your company details and logo once, and reuse them across all quotes.
* **Dashboard Analytics:** Track total generated revenue and quotation statuses (Draft/Completed).
* **Fully Responsive:** Beautiful glassmorphic, premium UI that works on desktops, tablets, and mobile devices.

## 🛠️ Technologies Used

* **HTML5:** Semantic markup.
* **CSS3:** Custom CSS with a premium monochromatic design system.
* **Vanilla JavaScript:** Full application logic, state management, and DOM manipulation.
* **html2pdf.js:** For client-side PDF generation.
* **Phosphor Icons:** For clean, modern UI icons.

## 🚀 How to Use

Since QuoteCraft is a purely frontend application, you don't need to install any dependencies or local servers.

1. Download the ZIP file of this repository or clone it.
2. Extract the ZIP file to your computer.
3. Open the `index.html` file in any modern web browser (Chrome, Edge, Firefox, Safari).
4. Start creating quotations immediately!

## ⚠️ Important Note on Data Storage

All data is stored locally in your browser's `localStorage`. This means:
* Your data is completely private and never leaves your device.
* If you clear your browser data or cache, your saved quotations will be deleted.
* Quotations are device-specific (creating a quote on your laptop won't show up on your phone).
